# Foundations

## Purpose

Identify the smallest useful set of primitives from which other concepts might be defined. The current list is provisional, not an assertion that these concepts are irreducible.

## Candidate primitives

1. **Entity / subject of discourse** — whatever the framework is currently about. This does not settle whether the referent exists physically, abstractly, mentally, or only as a representation.
2. **Existence status** — the mode in which an entity is being considered (physical, abstract, fictional-as-represented, experiential, formal, or unresolved). These categories may overlap and require revision.
3. **Distinction** — a criterion under which two descriptions, states, or entities count as different.
4. **Property / state** — a specified feature or condition attributed to an entity.
5. **Relation** — a specified way that two or more relata are associated, ordered, compared, or dependent.
6. **Representation** — a symbol, model, or state used to stand for something under an interpretation.
7. **Transformation** — a specified mapping from one state, description, or configuration to another.
8. **Validity conditions** — the conditions under which a proposition or model is assessed.

## Dependency questions

- Can entity be defined without identity or distinction?
- Does a relation require two distinct relata, or can a formal system represent self-relations?
- Is distinction primitive, or is it defined by a relation?
- Is measurement a type of relation, a procedure applied to relations, or both in different senses?
- Does existence need one universal definition across physical, abstract, and fictional discourse?
- Which concepts require an observer, and which do not?

## Formalization rule

For each proposed primitive, document: (a) an informal definition, (b) a formal type or signature, (c) assumptions, (d) examples, (e) counterexamples, (f) domain limitations, and (g) dependencies on other primitives.

Do not call the foundation complete until alternatives and circular definitions have been examined.
