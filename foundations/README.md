# Foundations

## Purpose

Identify the smallest useful set of formal primitives for the framework and for a candidate intelligent system. The list is provisional: a primitive is relative to a chosen formal language and task, not automatically a fundamental constituent of reality.

## Candidate concepts

1. **Domain / state space** — the set of possibilities currently being modelled.
2. **Distinction** — a criterion-dependent separation between alternatives, states, descriptions, or outcomes.
3. **Entity / referent** — something the system tracks or reasons about; its persistence conditions remain to be specified.
4. **Property / state variable** — a feature or value attributed within a model.
5. **Relation** — a structured association among one or more relata.
6. **Representation** — an encoding used by a system to stand for something under an interpretation.
7. **Transformation** — a mapping from one state, representation, or configuration to another.
8. **Observation / evidence** — an input that constrains which states or models remain plausible.
9. **Validity criterion** — a rule for evaluating a claim, model, inference, or measurement.

These candidates are not asserted to be mutually independent. Some may be definable in terms of others.

## Key distinction: world primitives vs computational primitives

A **world primitive** is claimed to be fundamental to what exists. A **computational primitive** is a basic operation or data type chosen to implement a system. The two need not match. A useful system may start from convenient computational objects without claiming that reality is literally made of those objects.

## First dependency questions

- Can a distinction be defined without presupposing alternatives and a criterion?
- Can an entity be represented as a stable pattern rather than an irreducible object?
- Does a relation require distinct relata, or can self-relations and higher-arity relations be represented?
- Is measurement a relation, a procedure, a result, or a structured combination?
- What enables a representation to refer to something beyond its own internal symbols?
- Which primitives are required for a task, and which are merely convenient?

## Formalization rule

For every proposed primitive, record: (a) informal meaning, (b) formal type/signature, (c) assumptions, (d) examples, (e) counterexamples, (f) domain limits, (g) dependencies, and (h) computational use.

Do not call the foundation complete until alternatives, circular definitions, and counterexamples have been examined.
