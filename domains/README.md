# Domain mappings

The project aims to investigate recurring structures across domains without assuming that a shared word implies a shared mechanism.

Initial domains:

- Physics and physical systems
- Mathematics and abstract structures
- Logic and language
- Psychology and cognition
- Conscious experience
- Fiction, imagination, and representation
- Ethics, conscience, and moral reasoning
- Social systems

For every cross-domain mapping, document:

1. the source concept and target concept;
2. the shared structure being proposed;
3. the domain-specific interpretation of each variable;
4. where the analogy breaks;
5. evidence or derivation supporting the mapping;
6. predictions or useful consequences;
7. counterexamples and alternative models.

Do not treat metaphorical similarity as mathematical identity.
