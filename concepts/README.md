# Concept registry

This directory holds one evolving specification per core concept. Definitions here are provisional until explicitly marked otherwise.

## Initial concepts

- [Relation](relation.md)
- [Measurement](measurement.md)
- [Perspective](perspective.md)
- [Truth and stability](truth-and-stability.md)

## Required fields for each concept

- ID and status
- Origin / intended meaning
- Working definition
- Candidate formalization
- Examples and non-examples
- Cross-domain interpretations
- Dependencies
- Counterexamples and failure conditions
- Revision history

A word appearing in several domains does not guarantee that the same formal object or mechanism applies in each domain.
