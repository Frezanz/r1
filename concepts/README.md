# Concept registry

This directory holds evolving specifications for core concepts. Definitions remain provisional until their assumptions, scope, counterexamples, and validation conditions are explicit.

## Current entries

- [Relation](relation.md)
- [Measurement](measurement.md)
- [Perspective](perspective.md)
- [Truth and stability](truth-and-stability.md)
- [Framework filter](framework-filter.md) — working proposal for tagging, connecting, and ordering items by truth status, time, meaning, value, mattering, evidence, and relevance

## Required fields for each concept

- ID and status
- Origin / intended meaning
- Working definition
- Candidate formalization
- Examples and non-examples
- Cross-domain interpretations
- Dependencies
- Counterexamples and failure conditions
- Revision history

A word appearing in several domains does not guarantee that the same formal object or mechanism applies in each domain. Preserve ambiguity until it is resolved by argument or evidence.
